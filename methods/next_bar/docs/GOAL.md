# Next-bar prediction goal

## 第一目標

XAUUSD の M1、M5、M15、M30 について、次の完成足が up / down のどちらになるかを、未知期間で再現可能な形で予測する。各予測には校正済み信頼度を付ける。

## 採用条件

単一期間の最高精度では採用しない。各時間足について以下を満たす候補だけを次の walk-forward 段階へ進める。

1. test accuracy と balanced accuracy が多数派ベースラインを上回る。
2. 前足方向をそのまま予測するベースラインを比較対象に含める。
3. Brier score、log loss、ECE が未校正確率より悪化していない。
4. 高信頼度帯の精度上昇が、十分な coverage を伴っている。
5. 年・月・時間帯・volatility regime を変えても優位性が一部期間だけに集中しない。

## 入力表現の原則

- OHLCの生価格水準をモデルへ直接入力しない。
- 手動設計では、価格差をリターン・ATR比・rolling z-score・ローソク足比率・momentum・volatilityなどの定常化表現へ変換する。
- 深層学習では、生価格列ではなく正規化した変化系列を入力する。
- 新しい表現はtestを見て採否を決めず、複数walk-forward foldで比較する。

## 次段階

1. expanding walk-forward の複数窓評価。
2. 予測誤りを時間帯、ボラティリティ、足形、連敗系列で分解。
3. 特徴量・モデル候補を固定した事前登録型の比較。
4. 校正済み確率を入力とする売買 policy を別実装し、方向モデルを再学習せずにコスト・見送り・複数時間足合意を最適化。
