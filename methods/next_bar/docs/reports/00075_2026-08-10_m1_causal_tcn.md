# 00075 M1 Causal TCN

日時: 2026-08-10 23:03 JST

## 目的

手動指標とは独立した学習経路として、M15で事前固定済みの小型因果TCNを仕様変更せずM1へ移植した。結果確認後にwindow、channel、epoch、capacity、blend weightを再探索せず、方向edgeとconfidence選別edgeを分離して評価する。

## 固定仕様と品質

直近16完成足のATR正規化return/body/range、中心化close location、ATR正規化wick balanceの5系列だけを使う。raw価格水準とvolumeは入力しない。各foldのtrain内だけでchannel標準化し、2層dilated causal convolution、hidden 16、1,073 parameter、8 epoch、batch 2,048、AdamW、seed 42を固定した。baseline/TCNともsource 6,025,170行、usable 5,737,928行、OOS 2,183,717行で完全一致する。

完全無変動足のATR比とclose locationの0/0を「値動きの証拠なし」の0へ定義し、flat区間の80 sequence列が有限0になる回帰テストを追加した。未来足改変で現在sequenceが変わらない既存因果性テストも維持した。学習時はM1全特徴を一括保持して約20GBまで使用したため、将来の再学習運用ではfold別feature materializationを品質改善項目とする。

TCN単体はbaseline比-1,970件、p=0.00615、accuracy改善2/7foldのため棄却した。通常25%方向blendはBrier/log lossを6/7fold改善したが、accuracyは5/7fold、確認期間の純改善は125件だけである。UTC日bootstrapのaccuracy差95%区間もdevelopment -0.0073〜+0.0770pt、confirmation -0.0359〜+0.0658pt、全期間 -0.0054〜+0.0587ptで0を跨いだ。Path Persistence方向候補より弱いため方向用途には採用しない。

## 方向維持confidence 0.515

baseline方向を完全に維持し、確率edgeの大きさだけbaseline 75% + TCN 25%で補正した。閾値は2020〜2023だけのcoverage-aware scoreから0.515を選び、2024〜2026途中を確認に使った。

| period | baseline accuracy / coverage / score | TCN confidence accuracy / coverage / score |
|---|---:|---:|
| development | 51.95049% / 28.6110% / 0.009587 | 52.15947% / 25.8024% / 0.010123 |
| confirmation | 52.50910% / 9.9208% / 0.006837 | 53.04138% / 7.9411% / 0.007506 |
| all | 52.05067% / 21.3852% / 0.008820 | 52.30275% / 18.8971% / 0.009348 |

accuracyは7/7fold、selection scoreは6/7fold、Brier/log lossは各6/7fold、ECEは5/7fold改善した。全件確率品質もBrier 0.24986888→0.24985390、log loss 0.69288487→0.69285481、ECE 0.20289%→0.11886%へ改善した。

UTC日paired bootstrap 20,000回のcandidate−baseline accuracy差95%区間はdevelopment +0.1301〜+0.2891pt、confirmation +0.3156〜+0.7478pt、全期間 +0.1760〜+0.3273ptで改善側だった。selection score差もdevelopment +0.000134〜+0.000943、confirmation +0.000039〜+0.001302、全期間 +0.000195〜+0.000855で改善側だった。coverageは約2〜3pt減るが、精度とcoverageの合成目的関数として改善している。

## 信頼度をoddsとみなせるか

0.515以上の全期間は412,659件、accuracy 52.30275%、mean confidence 52.41286%でWilson区間内だった。一方、確認期間は67,042件、accuracy 53.04138%、mean confidence 51.97185%で1.0695pt過小評価し、局所整合しない。0.515→0.525→0.535では確認精度が53.04%→56.06%→57.57%へ上がるが、0.55は58件だけで48.28%へ崩れる。高閾値へ変更しない。

prior OOSだけで次foldを測るnested 1,838,693件では、TCN raw confidenceがbaselineよりBrier 0.24991283→0.24990158、log loss 0.69297286→0.69295030、ECE 0.18571%→0.13173%と全て改善した。追加isotonicはECEだけを改善してBrier/log lossを悪化、correctness Plattは3指標とも悪化したため使わない。global odds gateは通るが、確認期間の局所不整合とruntime blend parity未検証によりfair oddsは非認可とする。

固定side×volatility監査では確認0.515のWilson edgeがdown-high 11,333件、up-high 42,895件、up-normal 8,194件で成立した。down-low 613件、down-normal 2,389件、up-low 1,618件は未達だった。事後のsubgroup filterは作らず、この6セルをfresh監視条件として固定する。

## 判断

`m1_tcn_confidence_candidate_v1.json` にM1 selective confidenceのparallel forward候補として固定する。方向はbaselineを維持し、threshold 0.515、sequence、TCN仕様、25% weightを変更しない。Path Persistence方向候補とは役割が異なるためstackしない。

authoritative方向、confidence、fair odds、paper/live policyは変更しない。完全未使用期間で0.515 accuracy・selection score・Brier・log loss、固定6 subgroup、runtime probability parity、局所校正を再確認してから昇格を判断する。
