# 00088 M1 Causal GRU

日時: 2026-08-11 04:13 JST

## 目的

TCNとは異なる系列帰納バイアスを固定比較するため、同じ直近16本×5加工系列を単層causal GRUへ入力した。M1結果を見てwindow、hidden、epoch、学習率、weight、confidence閾値を変更せず、方向、方向維持confidence、既存disagreementへの増分を分離して評価する。

## 固定仕様と品質

入力はATR正規化return/body/range、中心化close location、ATR正規化wick balanceだけで、生価格水準とvolumeは使わない。各foldのtrainだけでchannel標準化し、hidden 16、8 epoch、batch 2,048、AdamW、learning rate 0.001、weight decay 0.0001、seed 42、train上限750,000、後続PlattをTCN条件へ揃えた。

PyTorch GRUは各gateに2組のbiasを持つため1,121 parameterで、TCN 1,073より48、4.47%多い。hidden 15は1,006で差が大きいため近いhidden 16を事前仕様のまま使い、結果後に容量を変更していない。

source 6,025,170行、usable 5,737,928行、OOS 2,183,717行はbaseline/TCNと一致した。decision/target timestamp、target、foldも全件一致し、7 artifactすべて1,121 parameter・8 loss点を確認した。`python -m trade_data.next_bar` で校正器が `__main__` として保存される問題を監査中に検出したため、canonical moduleへ再入場するentrypointへ修正し、別プロセスtrain→latest回帰テストを追加した。今回artifactもportable module名へ再packし、別プロセス7/7読込を確認した。

## 方向維持confidence 0.515

baseline方向を完全維持し、baseline 75% + GRU 25%のedge強度だけを使った。TCN/Disagreementと同じ0.515を固定し、別閾値の採用探索はしていない。

| period | baseline accuracy / coverage / score | GRU accuracy / coverage / score |
|---|---:|---:|
| development | 51.9505% / 28.6110% / 0.009587 | 52.1217% / 26.8953% / 0.010157 |
| confirmation | 52.5091% / 9.9208% / 0.006837 | 53.0222% / 8.4931% / 0.007743 |
| all | 52.0507% / 21.3852% / 0.008820 | 52.2712% / 19.7809% / 0.009439 |

accuracy・selection scoreはbaseline比7/7foldで改善した。TCN 0.515比ではall coverage +0.8838pt、accuracy -0.0316pt、score +0.000091で、accuracy/score/proper scoreのbootstrap区間は0を跨ぎ、coverage増加だけが確定した。

5-model Disagreement比ではall accuracy -0.0377pt、coverage -0.1150pt、score -0.000198。accuracy/score差は日次区間で未確定だが、coverageは明確に少なく、全行Brier差95%区間 +0.00000387〜+0.00001071、log loss +0.00000777〜+0.00002147でGRU悪化が確定した。既存balanced challengerを置換しない。

confirmation 0.515は71,702件、accuracy 53.0222%、mean confidence 51.9749%で1.0474pt過小評価し局所整合しない。0.525は55.726%、0.535は58.308%へ上がるが、0.55は47件・40.426%へ崩れるため閾値を動かさない。固定6セルはdown-high、up-high、up-low、up-normalでWilson edgeを通り、down-lowは48.440%、down-normalは50.606%で未達だった。事後filterは作らない。

## 6-model Disagreement感度

既存baseline/Path/Extra Trees/LightGBM/TCNの等重み平均へGRUを6番目として追加し、penalty 0、baseline方向維持、0.515を固定した。weight sweepはしていない。

|---|---:|---:|
| development | 52.1609% / 26.9153% / 0.010365 | 52.1785% / 26.2558% / 0.010317 |
| confirmation | 53.0306% / 8.7589% / 0.007904 | 53.1290% / 8.1919% / 0.007891 |
| all | 52.3089% / 19.8959% / 0.009636 | 52.3347% / 19.2722% / 0.009587 |

6-modelはaccuracyをall +0.0258ptにしたが、coverage -0.6237ptでselection scoreを-0.0000495にした。accuracy/scoreの日次区間は0を跨ぎ、coverage低下は明確だった。development proper scoreは改善した一方、confirmationは点悪化、all改善区間も僅かに0を跨いだ。目的関数を改善しないため追加を棄却する。

## 判断

GRUと6-model拡張は再現専用とする。独立sequence edgeは確認できたが、方向では既存候補、selective confidenceではTCN accuracy specialistと5-model Disagreement balanced challengerを超えない。config、latest shadow、odds、policyは発行・変更しない。同じ履歴でGRU仕様、blend weight、disagreement部分集合、0.515以外の閾値を再探索しない。
