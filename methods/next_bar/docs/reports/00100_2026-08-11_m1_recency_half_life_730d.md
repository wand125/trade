# 00100 M1 Recency Half-Life 730 Days

日時: 2026-08-11 09:51 JST

## 目的

相場構造の時間変化へ学習側から対応するため、expanding trainingの古い行を捨てず、decision timestampの新しさに応じて連続的に重みを下げる方法を検証した。棄却済みの固定3年training windowは境界より古い履歴を完全に捨てるが、今回は全履歴を保持するため別の学習フローである。

## 固定仕様と品質

`--train-weighting recency_half_life_730d` を追加した。各foldのsampled train内で最も新しいdecision timestampを基準にageを日数へ変換し、`2 ** (-age_days / 730)` を計算して平均1へ正規化する。0日、730日、1460日の相対重みは1、0.5、0.25である。上限750,000行のsampleはexpanding履歴の先頭から末尾までを等間隔で取り、直近行だけへ置き換えない。

重みはHGBのtrain fitだけに渡し、calibrationとtest評価には使わない。各test foldで利用可能なtrain timestampだけから計算し、未来test、未来label、現在targetは参照しない。timestamp欠損・不正値・負のageは停止する。比率、平均1、欠損guard、small pipeline、artifact latest推論をテストした。

baseline 38特徴、HGB 200 iteration、31 leaves、learning rate 0.05、min leaf 100、L2 1、expanding train最大750,000行、Platt、seed 42を維持した。source 6,025,170行、usable 5,737,928行から、baselineとkey、target、foldが一致する2,183,717 OOS行を生成した。通常・方向維持ともbaseline 75% + recency candidate 25%で、損失倍率は標準1.0のみである。

## 単体と通常方向blend

| period | baseline | Recency単体 | 通常25% blend |
|---|---:|---:|---:|
| development | 50.93738% | 50.83951% | 50.95537% |
| confirmation | 50.60001% | 50.55559% | 50.64502% |
| all | 50.80695% | 50.72974% | 50.83539% |

Recency単体はbaselineよりall -1,686件、exact paired p=0.00959で、accuracy・Brier・log lossは各2/7foldしか改善しなかった。近時データを強くした単体置換は明確に棄却する。

通常25% blendはbaseline比development +241件、confirmation +380件、all +621件で、accuracy 5/7fold、Brier/log loss 6/7foldを改善した。UTC日paired bootstrap 20,000回ではall accuracy差95%区間が+0.00023〜+0.05674pt、Brier/log lossも改善側だった。developmentとconfirmationのaccuracy区間は0を跨いだが、全期間のproper score改善は確定したため、recency weightingがbaselineと異なる誤りを一部直すこと自体は再現した。

しかし既存Distribution Shift通常25% blendはdevelopment 50.97359%、confirmation 50.64431%、all 50.84629%で、Recencyはconfirmationだけ6件上、developmentとallで下回った。直接比較はDistribution Shiftがaccuracy/score 4/7fold、Recencyが3/7foldで、all accuracy差95%区間はDistribution Shift−Recencyで-0.02098〜+0.04220pt、Brier/log loss差も0を跨いだ。統計的な差は未確定だが、既存候補の全期間accuracy・proper score点推定を超えず、同じstability/probability-quality役割を増やさない。

## 方向維持confidence 0.515

development固定grid `0.51, 0.515, 0.525, 0.535, 0.55` のcoverage-aware score最大は0.515だった。

| period | baseline accuracy / coverage / score | Recency accuracy / coverage / score |
|---|---:|---:|
| development | 51.9505% / 28.6110% / 0.009587 | 52.0776% / 27.0848% / 0.009966 |
| confirmation | 52.5091% / 9.9208% / 0.006837 | 52.7837% / 8.5229% / 0.007061 |
| all | 52.0507% / 21.3852% / 0.008820 | 52.1945% / 19.9087% / 0.009129 |

baseline比ではaccuracy 6/7fold、score 5/7foldを改善した。日次bootstrapはdevelopment/allのaccuracyとscore改善、confirmationのaccuracy改善を支持した。confirmation score差は95%区間が0を跨いだ。

一方、同じ0.515の5-model Disagreementはall 52.3089% / coverage 19.8959% / score 0.009636で、ほぼ同じcoverageのRecencyをaccuracy +0.1144pt、score +0.000507上回った。直接比較でDisagreementはaccuracy 5/7、score 7/7fold勝ち、all日次95%区間はaccuracy +0.03716〜+0.19137pt、score +0.000164〜+0.000850、Brier/log lossも改善側だった。confirmationでもaccuracy、coverage、scoreが全て優位である。Transition guard 50/50 accuracy championとDistribution Shift ultra-broad候補にも全期間scoreが届かず、confidence候補へ追加しない。

## 高信頼度と局所品質

全期間0.55以上は15,044件、coverage 0.6889%、accuracy 55.4906%、0.575以上は1,620件、58.3333%だった。ただし0.575以上は全件developmentで、confirmationは0件である。confirmation 0.55以上も112件、accuracy 54.4643%に留まり、固定6セルは全てWilson edge未確認だった。

固定0.515のconfirmationはup-high 47,053件・53.1252%、down-high 13,117件・52.6492%、up-normal 7,484件・52.2314%だけがedge確認済みだった。down-low 569件・48.3304%、up-low 1,331件・49.7370%、down-normal 2,400件・51.2917%は未確認で、6セル中3セルしか通らない。結果を見た後のsubgroup除外ruleは作らず、fair odds・policyには使わない。

latest artifactは2026-06-01 04:59 UTC判定でdown、probability down 51.3136%を返し、保存・推論経路を確認した。empirical odds calibrationなしのため `odds_valid=false` である。

## 判断

730日半減Recency weightingの単体、通常25%方向blend、方向維持0.515を再現専用として棄却する。通常blendはbaselineに対する小さな補完性とproper-score改善を再現したが、既存Distribution Shiftの点推定を超えず独立した役割がない。confidenceはbaselineを有意に改善しても、同coverageのDisagreementに精度・selection score・確率品質で明確に劣り、高信頼度tailと局所確認期間も弱い。

730日半減、重みfloor、sample方法、blend weight、0.515以外の閾値を同じ履歴で再探索しない。Path/Distribution Shift方向候補、Transition guard/Disagreement/Distribution Shift confidence候補を維持し、config、registry、authoritative方向/confidence、fair odds、paper/live policyを変更しない。
