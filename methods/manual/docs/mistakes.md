# 失敗パターンと対策

繰り返しやすい失敗のカタログ。journal で同種の失敗が2回以上現れたらここに登録する。

各項目は次の形式で書く:

```markdown
## 失敗パターン名

- 発生 journal: 00xxx, 00xxx
- 症状: 何をやってしまうか
- 引き金: どういう状況・心理で起きるか
- 損害: 典型的にどれくらい失うか
- 対策: 具体的な防止ルール(principles.md に昇格させたら番号を記す)
```

---

## 動き出した相場を追いかけてエントリーする

(本人の自認に基づき Claude が代筆、2026-08-04)

- 発生: 2026-07-31 12時台 USDJPY — 上昇を追って 159.56 買い → 159.80 買い → 159.83 買い(各100ロット)、いずれも数分で決済。ほか7月に複数回
- 症状: 動き出した値動きを見て、計画になかった価格で飛び乗る。エントリー根拠が「動いているから」になっている
- 引き金: 取り逃しの焦り。直前に見送った局面が伸びたとき
- 損害: 7/31 の3連発だけで −26,000円級の往復を含む。掴んだ位置が悪いため保有も浅く、損切りも投げになる
- 対策: **逃したら追わない。次の戻り(ゾーンの再試し)を待つ。** エントリーは事前に campaign.md に書いたゾーンとトリガーでのみ行う(出典: claude/00002 の7/31復元、2026-08-04の会話)
