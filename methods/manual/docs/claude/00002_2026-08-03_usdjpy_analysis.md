## 訂正(2026-08-04、詳細は [[00003]])

- **ロット単位**: 本口座は1ロット=1,000通貨(マイクロ)。「100ロットで1pip≈10万円」は誤りで、正しくは **1pip=1,000円**。最大建玉140ロット=14万ドル(レバレッジ約55倍)
- **「隠れコスト4.9万円」は誤り**: ヘッジ口座のためFIFO対応付けが一部ずれていた。7/31 16:42の−88,753円は「−4pips+コスト」ではなく、**7/30夜に158.58で建てたショートの−88.75pips**。期間全体のスワップ実額は−14,191円
- 本人より: 7/13〜のショート&ナンピンは**為替介入狙い**だったとの補足あり。戦略として再評価した([[00003]])

## 実際に起きたことの時系列

1. **7/13〜7/27**: 162.41 / 163.16 / 163.68 と、上昇するUSDJPYに20ロットずつ3回ショートを積む(逆行への買い増し)。最大60ロット、含み損は一時25万円規模で口座残高を超えていたと推定
2. **7/30 17:42**: 159.5への急落で3本を一括利確 **+202,275円**。17日間のナンピン耐えが「成功」してしまう
3. **7/30 20:40**: 直後に158.6でショート5本(20ロット×5)を再度積む — 自分が獲った急落の底を売る形
4. **7/31**: 価格が160.6へ反発し再びナンピン地獄。以後、100ロットで数pipsのスキャルとドテンを繰り返す(2〜13pipsの勝ちと−26pips級の負けが混在)
5. **7/31 16:29 / 17:11**: 159.64 と 159.30 で計140ロットのロング — 下落トレンドへの逆張り
6. **7/31 23:33〜23:35(= 土曜5:33 JST、週末クローズ27分前)**: 157.9まで下げたところで投げ(またはストップアウト)、**−227,000円**。口座はほぼゼロに

## 構造的な発見

- **「勝ちパターン」が最危険パターンと同一**: 唯一の大勝ち(+202k)は、逆行に積み増して耐えるという、口座を飛ばすのと同じ行動から出ている。この成功体験が翌日の全損の直接原因
- **サイズが100ロットだと1pip≈10万円**。7/31の負けの大半は数pipsの逆行で発生しており、値幅ではなくサイズが死因
- **隠れコスト**: 100ロットを16時間持った7/31のショートは値幅−4pipsに対し損失−88,753円。手数料+スワップで約4.9万円が消えており、大ロットの持ち越しはスプレッド以外のコストが巨大
- ロングは全敗に近い(−237,900円)。この期間のUSDJPYは下落トレンドで、トレンドに逆らう方向だけで損失が出ている

## 昇格候補(本人の判断待ち)

1. mistakes: 「ナンピン成功」を成功と数えない — 生還した1回が次の全損を作る
2. principles: 含み損の玉に追加しない(方向別データ: 追加した局面だけで累計−30万円規模)
3. principles: 大ロットの持ち越し禁止(手数料+スワップの実測 −4.9万円/16時間/100ロット)
4. playbook候補(検証待ち): この期間唯一機能したのは「明確な下落トレンド方向のショート」のみ
