# プレイブック(セットアップ集)

再現できる型だけをここに載せる。思いつきの段階のものは journal に書き、複数回機能したことを確認してから昇格させる。

各セットアップは次の形式で書く:

```markdown
## セットアップ名

- 状態: 検証中 | 採用 | 停止
- 根拠 journal: 00xxx, 00xxx
- 相場環境: どういう地合い・時間帯で有効か
- 条件: エントリーの前提条件(すべて満たすこと)
- エントリー: トリガーと執行方法
- 損切り: 位置と根拠
- 利確: 位置と根拠、分割の有無
- 撤退: 想定が崩れたと判断する条件
- 注意: 誤発動しやすいケース
```

## 介入後の帯フェード(戻り売り)

(2026-08-04 の作戦01の的中を受けて Claude が代筆。本人の言葉への書き換え歓迎)

- 状態: 検証中(2026-08-04 にシナリオ的中を1回確認。実弾は未執行)
- 根拠 journal: 00001
- 相場環境: 介入・急落イベントの後の自律反発局面。上に明確な供給帯が控えていること。イベント直後の異常ボラが平常化しつつあるタイミング
- 帯の特定: ①直近週のクローズ水準(捕まった買い手・投げた売り手の記憶)②急落前の滞留帯 ③ラウンドナンバー — が重なる場所ほど強い(実例: 157.87〜157.94+158.00 → 高値157.943で拒絶)
- 条件: 反発が帯の下端〜内部に到達すること。**帯より下では入らない**
- エントリー: 帯内での失速確認 — M15の高値切り下げ+直近M15安値割れの確定。追いかけ禁止(逃したら帯の再試しを待つ)
- 損切り: エントリー+100pips目安、または帯上端の上(構造側)。ロットは式から: (残高×20%)÷(ストップpips×pip価値)
- 利確: 分割 — 直近サポート手前で一部、急落安値の再試しで残り
- 撤退: 帯の上抜け定着(無効化)。全戻し型(2024年5月の前例: 介入後2ヶ月で160円へ全戻し)では踏み上げられるため、無効化を痛みで動かさない
- 注意: ①資金は作戦確定時に配置しておく(journal 00001 — 入金が間に合わずトリガーを見送った)②イベント直後の高ボラレジームでは想定逆行を広げてロットを落とす
