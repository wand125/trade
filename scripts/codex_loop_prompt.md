**まず `AGENTS.md` を読んでください。**そこに書かれた禁止事項・作業の型・結論の書き方の原則にすべて従います。特に **売買は絶対に行わない**、`runtime/` は読み取り専用、という2点は例外なく守ってください。

## この起動でやること

**「次の検証」を1件だけ処理して終了します。**複数まとめて進めないでください。1起動=1件です。

1. `methods/next_bar_ev/docs/status.md` の「次の検証」を読む。ここに着手可能な項目がなければ `methods/next_bar/docs/status.md` を見る
2. **上から順に、着手可能な最初の1件**を選ぶ。すでに完了しているもの、外部要因で待ちのものは飛ばす
3. 実行する。**既存の成果物(`experiments/` 配下、13GB)は再計算せず読み取る**。再学習が必要だと判断したら、それが本当に必要かを1行で説明してから行う
4. 結論を **採用(accepted)/棄却(reject)/shadow・candidate 止まり** のいずれかで明示する。**標準判断は `NoTrade`**
5. `docs/reports/` に連番でレポートを追加する(`000NN_YYYY-MM-DD_主題.md`)。既存レポートの書式に合わせる
6. `docs/status.md` の「現在の状態」と「次の検証」を更新する
7. **commit して push する**(現在のブランチへ。PR は不要)

## 出力の約束(ループが状態を判定するために使います)

最終メッセージの**最終行**に、必ず次のいずれか1つだけを書いてください。

- `LOOP_STATUS: DONE <一行要約>` — 1件処理してcommit/pushまで完了した
- `LOOP_STATUS: NOTHING_TO_DO <理由>` — 着手可能な項目がなかった
- `LOOP_STATUS: BLOCKED <理由>` — 人間の判断や外部要因が要る。**勝手に代替案へ進まないこと**

## 守ること

- **データや前提が足りないときは、埋めずに `BLOCKED` で止まる**。推測で数字を作らない
- **`experiments/`・`data/`・`runtime/` はコミットしない**(.gitignore 済み)
- **口座情報・認証情報をコミットしない**
- このマシンでは ComfyUI / Ollama / Open WebUI などが常時稼働しています。**それらのプロセスを停止しないでください**
- 長時間かかる処理を始める前に、想定所要時間をレポートに書いてください
